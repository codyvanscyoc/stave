Stave is a minimal Mac menu bar app for writers, worship leaders, and creative thinkers.
Write mode — a distraction-free songwriter's notebook with rhyme finder, syllable counter, WEB Bible concordance, WordNet synonyms, and a curated worship vocabulary. Lock In opens a full-screen writing environment with three visual themes — Stave, Manuscript, and Midnight — plus a living outline and word count.
Plan mode — stream-of-consciousness meeting notes with automatic task extraction, reminders with Mac notifications, and iCloud sync. Lock In opens a full project planning workspace with a brain dump canvas, extracted task list, phase buckets, Gantt-style timeline, links and references, and multi-project switching via colored dots.
Notes save automatically to iCloud Drive as plain markdown files.
Built with Electron. Requires macOS with Apple Silicon (M1 or later).
